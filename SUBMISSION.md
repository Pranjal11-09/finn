# Final submission steps

1. Run setup. Fill .env with your own model key and available model IDs.
2. Run tests and preflight. Resolve every FAIL; do not represent fixtures as live data.
3. A dated source snapshot is included. Refresh it if the demo needs a newer fallback.
4. Push to your GitHub repository. Keep secrets out of Git.
5. Deploy using render.yaml and configure matching environment variables.
6. On a phone, open the deployment in a private browser:
   - Choose a recent window and open a results filing. The verified Kaynes example was filed on 14 Nov 2026.
   - Compare displayed numbers to the original.
   - Try Done/Keep/Less and reload.
   - Research ASIANPAINT (check the promise ledger) and a ticker outside the demo set.
   - Open citations and ask a follow-up.
   - Confirm unavailable evidence and feed failures are understandable.
7. If claiming phone alerts, configure Telegram and GitHub Actions and confirm receipt.
8. Export/share the AI build conversations, removing credentials.
9. Fill every placeholder in WRITEUP.md. Make sure all links work without your login.
10. Send the email yourself to assessment@enam.com with the specified subject.
